===========================================
使用 WinSCP 部署到腾讯云
===========================================

步骤 1: 下载并安装 WinSCP
-------------------------------------------
下载地址: https://winscp.net/eng/download.php
选择: Installation package
安装后打开 WinSCP

步骤 2: 连接到服务器
-------------------------------------------
1. 点击"新建站点"
2. 填写连接信息:
   文件协议: SFTP
   主机名: 119.29.84.36
   端口号: 22
   用户名: root
   密码: [输入你的服务器密码]

3. 点击"保存"（可选，方便下次使用）
4. 点击"登录"

步骤 3: 上传文件
-------------------------------------------
连接成功后，你会看到两个窗口:
- 左侧: 本地电脑文件
- 右侧: 服务器文件

1. 左侧导航到: D:\youhua\6541\
2. 找到文件: dist-update-20260302-183331.tar.gz
3. 右侧导航到: /root/
4. 将左侧的压缩包拖拽到右侧
5. 等待上传完成（265MB，可能需要几分钟）

步骤 4: 在服务器上解压部署
-------------------------------------------
上传完成后，打开 WinSCP 的命令行功能:
- 点击菜单: 命令 → 打开终端 (或按 Ctrl+T)

在终端中执行以下命令:

# 查看上传的文件
ls -lh /root/dist-update-*.tar.gz

# 解压文件
cd /root
tar -xzf dist-update-20260302-183331.tar.gz

# 查看你的网站目录
ls -la /root/

# 进入网站目录（根据实际情况修改路径）
cd /root/artislife

# 备份旧版本
mv dist dist.backup.20260302

# 移动新版本
mv /root/dist .

# 重启服务
pm2 restart all

# 清理压缩包
rm /root/dist-update-20260302-183331.tar.gz

步骤 5: 验证部署
-------------------------------------------
1. 打开浏览器访问: http://119.29.84.36
2. 清除浏览器缓存 (Ctrl+Shift+Delete)
3. 进入游戏 → 趣味游戏 → 一杆进洞
4. 检查是否显示中文
5. 玩到第16关，应该是"机器人迷宫"
